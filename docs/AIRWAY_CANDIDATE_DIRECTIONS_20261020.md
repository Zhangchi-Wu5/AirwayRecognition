# 气管镜静态图像方案的可尝试方向

日期：2026-10-20。定位：技术候选与最低成本验证，不是新颖性结论或授权预测。

当前仅有静态图片，没有视频或相邻帧。本轮实现范围是旋转约束的受控对照；以下其他方向先作为候选，不一并加入模型。

## 先确定要解决的实际问题

当前内部测试为 99 张图、34 位患者。ResNet 基线平均准确率约 98.32%，继续争取一两张图的分类提升，很难提供稳定证据。可以研究“关键依据是否可见、依据是否正确、输入变化时是否可靠”，但必须事先定义指标，并与已有简单方法比较。若方向没有取得对应收益，应调整或停止，不能换一个指标包装既有负结果。

三个种子不是三个独立患者队列；合成旋转或遮挡也没有增加独立患者数。当前测试集已经多次用于分析，后续试验宜在训练/验证部分开发，现有测试结果作为探索性结果。可信的最终验证仍应使用未参与选择的独立患者数据；当前只有这些图像时，应明确这一限制。

## 1. 共同可见区域内的旋转一致性

**具体问题：** 同一张图轻微旋转后，识别依据和输出是否改变？希望在结构仍可见时保持稳定，而不是强迫裁掉关键结构的图片给出同样答案。

**候选步骤：**

1. 对同一原图建立旋转配对，并记录几何变换和双方共同有效视野。反向对齐内部注意力图，只比较共同可见区域。
2. 在同一注意力结构上分别训练“无 EQ”和“有 EQ”；分类数据增强、裁边、PF、初始化、训练预算、BN 策略保持一致。若额外前向会改变 BN，必须采取两组一致的控制。
3. 同时检查预测稳定性、注意力对齐程度和注意力是否退化成均匀图。若注意力更一致而预测无改善，只能报告注意力一致性收益。

**数据和最低成本：** 现有静态图可生成配对，无需新增解剖标注。先在验证集做一个预定种子的受控试验，方向成立后再固定配置补种子。小角度旋转的幅度、插值、填充、有效区域须事先固定；大角度/明显裁切另列压力测试。

**必要对照：** 普通旋转增强、相同结构无 EQ、普通预测一致性损失。只比“完整方案 vs 普通 ResNet”不能归因到 EQ。

**成功指标：** 在共同原图正确队列中，旋转后正确变错率降低；逐图概率变化减小；注意力反向对齐误差降低且空间信息未塌缩。同时展示原图准确率、各类别表现及患者配对区间，不把“差异不显著”称为无损。

**最强相关工作与重合点：** SEAM（CVPR 2020，自然图像弱监督分割）已通过不同变换下的 CAM 一致性提供自监督；AugMix（ICLR 2020，通用图像分类）已结合增强与预测一致性。因此“旋转约束”“变换后保持一致”本身不是可直接宣称的新点。需要论证气管镜有效视野、可见证据与约束启用条件的具体方法及效果。[SEAM](https://openaccess.thecvf.com/content_CVPR_2020/html/Wang_Self-Supervised_Equivariant_Attention_Mechanism_for_Weakly_Supervised_Semantic_Segmentation_CVPR_2020_paper.html)，[AugMix](https://arxiv.org/abs/1912.02781)

## 2. 基于可见证据的可靠输出与拒识

**具体问题：** 高光、模糊或遮挡已经掩盖关键结构时，强制输出三个部位之一可能产生高置信错误。目标可以改为“依据不足时知道暂不判断”，而非要求任何受损图都分类正确。

**候选步骤：**

1. 为每张图估计有效视野、反光覆盖和少量结构依据的可见性；少量医生标注先确认“能否可靠辨认”及原因，防止把自动亮度阈值当成真实可见性。
2. 将校准后的分类置信度、解剖证据可见性、轻微变换下的分歧组成可靠性评分；仅在验证数据上确定规则或训练小型输出头。
3. 证据充分时输出部位与依据，证据不足时输出“当前图像不足以判定”。不将“拒绝更多图片”直接当作准确率提升。

**数据和最低成本：** 先利用现有预测概率建立最大 softmax 拒识基线；温度校准需要独立的验证集概率/标签。可先请医生对少量分层抽样图做“可辨认/不可辨认/不确定”评阅，确认现有图中确实存在该问题；如果全部是精选清晰图片，应承认现有自然样本不足。合成受损图只能证明受控压力场景的表现。

**必要对照：** 最大 softmax 阈值、温度校准后阈值、仅图像质量阈值、加入解剖证据后的方案。进一步开发学习式拒识时，可与 SelectiveNet 式选择头比较。

**成功指标：** 相同保留比例下错误更少，或相同错误水平下保留更多图片；报告风险—覆盖率曲线、不可辨认图的错误放行率、可辨认图的误拒率及分类别结果。不能只展示“被接受样本的准确率”。样本错误数很少时，拒识收益会高度不稳定。

**最强相关工作与重合点：** SelectiveNet（ICML 2019，通用分类/回归）已经联合学习预测与拒识；温度校准（ICML 2017）已经是低成本置信度校准方法。气管镜领域的 CN119313934A（2025-01-14 公开）已披露定位、有效图像和清晰度评价；US20260013701A1（2026 公开）涉及腔口位置与检查质量估计。因此“加一个质控/拒识模块”也不是新颖性结论。值得研究的是可核验的部位依据与可靠输出之间具体的计算关系，以及是否优于这些简单对照。[SelectiveNet](https://proceedings.mlr.press/v97/geifman19a.html)，[温度校准](https://proceedings.mlr.press/v70/guo17a.html)，[CN119313934A](https://patents.google.com/patent/CN119313934A/zh)，[US20260013701A1](https://patents.google.com/patent/US20260013701A1/en)

## 3. 少量结构标注约束的可核验识别依据

**具体问题：** 当前内部注意力有图可看，但还没有证据表明其对应临床上辨认部位所需的结构。直接限制高光重叠，可能只是把注意力挪到另一块无关组织。

**候选步骤：**

1. 由医生先定义每类图片中可用且可标注的辨认依据，例如确实可见的分叉、嵴或腔口区域；不要由模型开发者凭空指定左右支气管的充分判别条件。对训练/验证部分的小规模分层样本标粗区域或点，并标记“该依据不可见”。
2. 在原有模型增加轻量结构定位或可见性分支，利用少量标注约束注意力/局部特征；分类仍保留强基线。若分类可完全绕开解释分支，则不能把旁路显示的热图称为实际分类依据。
3. 做证据干预：遮挡医生标注的关键区域和面积相同的非关键区域，分别检查概率变化；结构不可见时降低可靠性，不强迫模型恢复原有自信。

**数据和最低成本：** 先进行标注与盲评的小型可行性试验，确认医生能一致标出依据；若一致性低，先调整定义，不急着训练。训练用标注与最终盲评标注须按患者分开。开始时无需把 641 张图全部做像素级标注。

**必要对照：** 原 ResNet 的同方法归因图、当前内部注意力、相同模型加普通空间监督/解释约束。所有热图使用相同目标类别、几何坐标和显示规则；不能拿内部注意力与未对齐 Grad-CAM 的颜色面积直接比较。

**成功指标：** 专家认可的结构覆盖率/点命中率、不同评阅者一致性、关键区域与非关键区域干预的差异、模型输出与可见性的一致程度，同时报告分类表现。漂亮热图、低高光重叠或低旋转误差，单独都不能证明解释忠实。

**最强相关工作与重合点：** Right for the Right Reasons（IJCAI 2017，通用可解释学习）已有根据专家注释约束解释/输入梯度的方法；Concept Bottleneck Models（ICML 2020，含 X 光分级与鸟类识别）已有先预测人可理解概念、再分类及概念干预的框架。因此“加入解剖概念”或“医生标注约束热图”只是已知方法类别，可能的技术贡献必须落在具体气管镜依据定义、可见性处理、分类耦合和效果证据。[解释约束](https://www.ijcai.org/Proceedings/2017/371)，[Concept Bottleneck Models](https://proceedings.mlr.press/v119/koh20a.html)

## 推荐顺序及暂不投入的方向

1. 本轮先完成 EQ 受控试验，验证当前设计有没有具体收益。
2. 同步用少量医生评阅判断“可见性不足/依据不正确”是否确实存在，以及是否可一致标注。若存在，再从可靠输出或结构依据中选一个方向。
3. 不同时堆叠多个新模块；不以换成 Transformer、加完整 CBAM、普通增强或普通温度校准作为已确认的专利创新。
4. 当前没有视频，无法验证拓扑状态转换、镜体进退推断、时序稳定和检查完整性。用不同患者或不同部位的静态图拼接不能替代真实序列；这些方向本轮不实施。

补充背景：Yoo 等 2021 年已研究隆突、左右主支气管的三分类，并使用随机旋转和圆形裁剪。因此“气管镜三分类＋旋转增强”本身已有很近的公开工作。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8660867/)

以上是有目标的研发候选。是否形成可保护的区别，需要在具体实现和有效结果出现后，再逐项与现有论文及专利权利要求比对；本记录不代表已做全面专利检索。
