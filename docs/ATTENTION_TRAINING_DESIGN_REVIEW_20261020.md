# 从训练开始学习／固定注意力：独立设计评审

日期：2026-10-20。状态：实施前设计评审，不含新实验结果。

## 结论与最小组别

建议默认只运行两组，回答“在相同训练条件下，允许注意力学习，相比始终固定注意力，是否改善分类表现”。不预设学习组更好。

| 组别 | 注意力初始化与训练 | PF权重 | EQ权重 | 旋转辅助前向 |
|---|---|---:|---:|---|
| `fixed_ce` | 空间卷积权重初始化为0并始终冻结，注意力恒为0.5 | 0 | 0 | 保留 |
| `learned_ce` | 相同零初始化，空间卷积参与训练 | 0 | 0 | 保留 |
| `learned_regularized`，可选 | 相同零初始化，空间卷积参与训练 | 0.1 | 0.1 | 保留 |

主比较为 `learned_ce − fixed_ce`。可选第三组相对 `learned_ce` 只检查PF和EQ联合正则的增量，不应将其差值命名为EQ单独效果。第三组相对 `fixed_ce` 同时改变注意力可学习性和联合正则，不用于单独归因。

若未来需要区分PF和EQ，应另行预先定义 `learned_pf_only` 桥接组；本次不必默认增加该组。已有历史EQ关闭组仍含PF=0.1，且使用随机注意力初始化，不能直接当作本实验的 `learned_ce`，也不能替代零初始化的桥接组。

## 为什么使用相同零初始化与固定0.5

现有空间注意力由无偏置卷积后接sigmoid产生。将卷积置零后，两组训练起点都为0.5，能同时匹配完整参数、缓冲区、初始注意力、初始输出及分类头输入尺度。学习组从相同起点获得更新机会，固定组不获得更新机会；不必改造已有分类头。

固定组保留原有全局分支和注意力分支，融合特征为 `[g, 0.5g]`，同时保留4096维分类头和dropout。其作用是消除输入相关空间加权，不是复现普通ResNet，也不意味着计算更省。学习组日后既能改变空间布局，也能改变平均幅度，所以本实验检查的是注意力可学习性的整体贡献，不能单独归因为空间布局。

新实验的共同零初始化与历史随机初始化不同。结果适用于本次规定的训练起点与预算，不能直接反推历史模型收益来自何种训练机制。

## EQ和PF的处理边界

固定均匀注意力的PF只是高光掩膜的面积比例，不提供可学习定位信号。其EQ在有效区域近乎平凡；现有有效阈值与插值可能残留极小边缘误差，不能据此宣称旋转一致性或解剖定位优秀。

因此两组主对照均关闭PF和EQ损失梯度。旋转辅助前向仍执行，避免同时改变BatchNorm更新次数和dropout随机数消耗。日志必须清楚区分“原始诊断量”与“实际加入总损失的权重”，不能把零权重辅助EQ误写为训练使用EQ约束。

## 必须匹配与核验的项目

- 每个种子下完整初始参数和缓冲区内容一致；对相同输入的初始注意力及logits一致。
- 同一数据划分、预处理、采样顺序、增强输入、批大小、训练种子、优化器设置、学习率日程和训练预算；各轮输入摘要一致。
- 所有组使用相同主图及旋转图前向调度、训练／验证模式和随机数调用安排。可记录随机数状态摘要验证调度。
- BatchNorm政策和更新次数一致。权重学习后各组特征不同，运行均值和方差自然可不同，不应强行匹配数值。
- 现有 `freeze_backbone()` 和 `unfreeze_all()` 都可能重新开放注意力参数；固定组必须在两个阶段保护冻结状态。
- 固定组训练后空间卷积仍精确为零，注意力恒为0.5，注意力梯度不参与更新；学习组确实能够收到分类损失产生的非零注意力梯度。
- 使用固定轮数末轮检查点作为主结果，最佳验证检查点只能作次要记录。新目录保存，保留失败与负向结果，不按结果替换种子或预算。

参数可训练数量不同是被研究的处理本身，不应为“参数量完全相同”再人为增加另一套可训练模块。架构与参数初始内容相同，不代表两组训练参数集合相同。

## 评价、输出与解释

沿用预定种子42、2026、3407和现有验证集，六个非零小角度平均分类准确率为主指标；0°结果单列。同步输出预测翻转率、共同原图正确队列的正确变错误比例、真实类概率变化、每类召回率和注意力分布诊断。

应保存逐图逐角度概率、逐种子结果、三种子等权均值与种子标准差，以及按患者共同重采样的配对差值区间。角度和种子不是新增独立患者。患者区间以所训练模型为条件，不包含未知训练种子的总体不确定性。可选第三组的每项比较须注明各自共同原图正确队列，不能把不同队列的比例直接相减作交互效应。

若内部复用旧EQ评估函数，应在导出时完整转换组名、比较方向和字段名，并由新协议校验训练来源。不得将“可学习／固定”伪装为 `eq_on／eq_off`。缺失、混用或矛盾的训练记录应明确失败或标为未核验。

研究边界：这次实验可检查从共同常数起点允许注意力学习的分类增量；不直接验证普通ResNet比较、历史EQ机制、定位正确性、真实反光鲁棒性或外部患者泛化。现有患者已用于多轮探索；若出现值得继续的信号，最终技术效果仍需未参与方案选择的新患者确认。

## 实现后的只读复核

同日审阅 `src/attention_training_control.py`、`scripts/run_attention_training_ablation.py` 和 `scripts/evaluate_attention_training_pairs.py` 的实现，未发现影响本设计解释的实质阻断。此项为源码复核，运行和测试结果另行记录，不以静态阅读替代真实运行。

- 固定组在两个训练阶段及检查点重载后都会恢复冻结政策，逐轮验证权重仍为零；学习组保留可训练参数。
- 两组先消耗相同普通模型初始化随机数，再将注意力卷积置零；比较完整初始状态摘要。
- 主对照实际传入PF=EQ=0，辅助旋转分支仍调用完整模型，包括分类头dropout。训练钩子检查每批两次训练前向、每批一次验证前向，以及BN调用次数和前向随机数状态；跨组摘要必须一致。
- 训练使用固定轮数末轮权重，并重新构建指定政策的模型验证保存和重载；现有第二阶段优化器即使包含冻结参数，也不会更新没有梯度的固定卷积。
- 评估中旧EQ组名只用于复用配对统计，所有导出模型名、比较方向和带组名字段均恢复为新对照名称。不同配对的共同正确队列分别标识，固定注意力在原图及旋转图中都核验为精确0.5。
- 评估核查训练来源、固定预算、输入与执行轨迹、检查点和验证划分摘要；推理仅打开验证图像。

当前评价入口每次处理一个训练种子，其患者区间不能替代三种子等权汇总或训练种子不确定性。学习组最终仍用学习后的注意力推理，固定组用常数注意力推理；因此这是“从训练开始允许学习”的整体对照，而不是只改变训练阶段、固定最终推理机制的中介效应实验。
