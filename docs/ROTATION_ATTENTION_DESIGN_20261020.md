# 固定权重的旋转与注意力替换诊断设计

日期：2026-10-20。本文预先规定下一轮诊断的比较对象、统计单位及解释范围，不包含尚未运行的服务器结果。

## 要回答的问题

此前三个训练种子的受控实验中，开启 EQ 相对于关闭 EQ，在六个非零旋转角度下的平均准确率约高 0.93 个百分点。干净图的注意力替换诊断显示，移除空间差异通常没有改变预测类别。

本轮检查：在同一批固定模型中，把旋转图的注意力铺平或打乱后，EQ 开启相对于关闭的准确率差是否改变。

0.93 个百分点是旋转输入上的两模型准确率差，包含两模型在干净图上已经存在的差异，不能直接称为“净抗旋转收益”。因此同时呈现干净图差异及旋转相对于干净图的变化。

## 冻结范围

- 三个训练种子 42、2026、3407，每个种子的 `eq_off` 和 `eq_on` 末轮权重，共六个模型。
- 原验证集 96 张图片、32 位患者；仅加载验证图像，不加载测试集图像。
- 固定角度 `[-15, -10, -5, 0, 5, 10, 15]` 度，不扫描或挑选角度。
- 沿用原裁边、缩放、中心裁切和 ImageNet 标准化。旋转发生在标准化之后，使用原 `_rotate`；填充的数值零表示 ImageNet 均值颜色。零度直接返回原张量，不做插值。
- 不训练、不校准 BatchNorm、不修改参数或缓冲区、不保存新模型。
- 仅增加独立诊断入口和统计代码，不修改训练过程、原模型前向接口或旧评估程序。

## 干预

对每张图的每个角度，先计算该输入自身的骨干特征 `F`、注意力 `A` 和全局特征，再固定 `F` 与分类头，仅替换 `A`。

| 模式 | 操作 | 作用 |
|---|---|---|
| `original` | 使用当前角度的原始注意力 | 核对原旋转结果，作为干预参照 |
| `mean_constant` | 把当前角度注意力的自身均值填满 7×7 网格 | 保持均值，移除空间差异，主要对照 |
| `spatial_shuffle` | 对当前角度原始注意力的 49 个值置换位置，重复 20 次 | 保持完整数值分布，破坏与特征位置的对应，主要对照 |
| `ones_constant` | 注意力全部设为 1 | 辅助检查幅度及门控作用 |

不能把干净图注意力的均值用于旋转图的铺平操作。那样同时改变空间差异和平均幅度，不符合本轮主要对照。

置换使用原诊断的确定性规则：评估种子、稳定 `case_id` 和重复编号共同决定 49 个位置的排列，不包含角度、模型名称、训练种子、批次或遍历次序。因此同一张图、同一重复在所有角度和模型中使用同一排列。各模型和角度仍使用各自原始注意力的数值。此规则也使零度结果能够与先前干净图诊断对应。

## 逐图记录与完整性

采用干净图诊断的预测字段并新增 `angle_deg`。其中 `original_prob_*` 始终表示**同一个角度、同一个模型未干预时**的概率；不表示干净图概率。

每个 `(seed, model, case_id, angle_deg)` 必须包括三个固定模式各一次和 `spatial_shuffle` 的完整连续重复。图片身份、患者、类别在所有角度、模型、种子和重复中保持一致。

保存三类完整概率，并独立复算以下派生字段，发现不一致时拒绝统计：

- 原始及干预后的预测和正确性；
- 干预引起的类别翻转；
- 同角度真实类别概率变化、原预测类别概率下降、概率向量 L1 变化；
- 注意力在原始 49 个网格上的平均绝对变化。

本轮主要问题不需要条件正确队列。为避免不同分母导致解释偏差，不加入“仅原始正确病例”的跨模型主比较。

## 主终点

设 `Acc(s, a, m, θ)` 为训练种子 `s`、EQ 设置 `a`、干预模式 `m`、角度 `θ` 的准确率。对 shuffle，先在同一图片和角度内平均所有重复；再在同一图片内平均六个非零角度；最后计算图像加权准确率。

首先为每种干预分别计算。本轮重新计算所有原始输出和原始差异，不把先前约 0.93 个百分点硬编码为分母或参照：

`G(s, m) = Acc(s, eq_on, m, 非零角度) − Acc(s, eq_off, m, 非零角度)`

直接回答问题的配对量为：

`D(s, m) = G(s, m) − G(s, original)`

`D` 是在同一患者、同一图片、同一组固定模型上的准确率差之差。其置信区间必须直接对配对量重采样计算，不能将两个置信区间的端点相减。

同时报告每个模型自身的准确率及“干预后减原始”的准确率差。即使 `G` 或 `D` 变化很小，也可能是两个模型受到类似幅度的损害；不能只展示模型间差值而隐藏双方表现。

不输出“收益保留百分比”。原始差异很小，比例会放大波动；直接以百分点表达更清楚。

## 辅助分解

为每个角度及零度分别输出两模型准确率和 `G`、`D`。另报告：

`R(s, m) = G(s, m, 非零角度) − G(s, m, 零度)`

`R` 描述两模型在旋转输入上的差异，相对于干净图差异改变了多少。它不是关于 EQ 如何通过注意力产生效果的因果中介估计。

无条件类别翻转率及概率变化用于辅助判断“类别不变但概率变化”的情况。多个角度和辅助指标是描述性分析，不据此筛选最有利结论。

## 抽样与不确定性

1. shuffle 先在图片和角度内部平均，六个非零角度再在图片内部平均。
2. 三个训练种子先分别计算效应，再等权平均；另报告三个种子效应的样本标准差。
3. 按患者进行 10,000 次成组 bootstrap。一个患者的所有图片在所有模型、模式、角度和训练种子中使用同一重采样次数。
4. 每次重采样直接计算 `G`、`D`、`R`，并报告其百分位区间。
5. 区间条件于当前六份固定权重，不代表未来重新训练的种子变化。

独立患者仍为 32 位。角度、20 次置换和三个训练种子不会增加独立患者数。区间包含零不能证明等价；本轮未预先定义等价界值，不作等价性检验。

## 实现验证与来源

- 分解的原始路径须逐批与正常模型前向核对 logits 和注意力，声明并记录数值容差。
- 模型运行前后所有参数及缓冲区的内容哈希必须相同，模型始终处于评估及推理模式。
- 对齐原实验的权重文件哈希、状态内容哈希、验证名单、类别顺序、配对初始化及训练输入追踪记录。
- 除原检查的 `src/attention.py`、`src/data.py`、`src/viz.py`，还须核对当前 `src/regularization.py` 与训练记录的源码哈希，防止旋转实现发生变化。
- 本次元数据记录新入口、统计模块及实际引用的预处理、旋转、注意力和辅助实现的源码哈希、软件版本、配置及输入文件哈希。
- 若自动发现既有旋转逐图预测文件，应核对图片、模型和角度的身份及完整矩形；身份或网格异常时报错。三类概率差异记录最大值和均值，类别不一致记录警告及元数据，不以很窄的概率容差阻止诊断：既有批大小和当前批大小不同，曾观察到最大约 `6.53e-4` 的概率差但类别一致。全部统计以本轮重新计算的原始模式为参照。没有旧文件时记录未核对，不能声称已复现旧结果。
- 零度诊断与原干净图诊断应在相同权重、参数和图片下吻合；跨批大小仅允许明确的数值计算差异。
- 输出目录不存在或为空才允许运行，不覆盖旧结果。结果失败时不能写为完成。

测试须覆盖：完整矩形及元信息校验、同角度参照、置换共享规则、旋转自身均值铺平、已知简单模型下的空间依赖、常数图置换不变、原始干预恒等、对角度和重复先平均、患者配对差之差的独立手算或枚举核验。

## 解释规则

- 若铺平及置换后 EQ 的旋转准确率差基本仍在，支持“当前固定模型间的这项差异不需要原注意力的空间图案才能在这些输入上表现出来”。不能由此断言训练期空间注意力从未发挥作用。
- 若差异减小，需同时查看 EQ 开启及关闭模型各自的变化，以及配对 `D` 的不确定性。仅凭干预后的一个准确率差或一条不显著结果不能证明机制。
- 若只有全 1 干预影响结果，不能把变化单独归因于空间位置；它同时改变了幅度。
- 干预改变输出，只能说明计算对该内部替换敏感，不能证明注意力定位了正确解剖结构。
- 输入旋转及内部干预可能产生训练分布之外的组合，本轮属于固定模型诊断，不直接证明临床效果、专利创新性或因果中介。

完成预定六模型、七角度及四模式的诊断后结束本轮；追加阈值、角度或结构改造应作为后续独立探索，不混入本轮固定设计。
