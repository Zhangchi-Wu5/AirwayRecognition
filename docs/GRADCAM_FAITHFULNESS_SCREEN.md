# Grad-CAM 遮挡依赖初筛

本轮只回答：**热图指出的高响应位置，是否比同面积随机位置更影响模型原来的判断？**

使用最近一轮区域实验中已训练的普通 ResNet 基线，不重新训练，不修改权重，不增加标注。这里的“过筛”是筛查解释方法是否值得继续研究，不是删除难例、筛选训练数据或筛选患者。

## 运行范围

- 输入：`region_relation_v1` 实验各个种子目录中的 `baseline/last_model.pt`、配置、训练轨迹及 `pair_metadata.json`。不需要其他三个模型的权重。
- 数据：原 `val` 划分；当前研究是 96 张、32 位患者。读取 train/test CSV 只核对身份及患者重叠，不打开其图片。
- 预处理：与本轮基线一致，RGB → Resize(256) → CenterCrop(224) → ImageNet 标准化，`crop_border=False`。
- 热图：在 `backbone.layer4` 计算原图预测类别的 Grad-CAM，然后对齐到实际输入的 224×224 图像。原图预测错时也保留，解释的是模型实际作出的判断。
- 用梯度计算热图，但不执行优化；模型始终处于评估模式，并核对运行前后模型参数和缓冲区未改变。

## 服务器命令

将本次新增脚本更新到服务器后，在仓库根目录执行。当前三个种子均使用原来固定 5+20 轮的 `last_model.pt`，不要混入后续不同训练预算的结果。

```bash
cd /opt/data/private/AirwayRecognition
conda activate airway

python -u -m scripts.screen_gradcam_faithfulness \
  --run-dirs \
    region_relation_ablation_v1/seed_42 \
    region_relation_ablation_v1_more_seeds/seed_2026 \
    region_relation_ablation_v1_more_seeds/seed_3407 \
  --splits-dir data_splits_patent \
  --image-root dataset \
  --output-dir gradcam_faithfulness_v1 \
  --device cuda \
  --batch-size 16 \
  --coverages 0.05 0.10 0.20 \
  --random-placements 20 \
  --bootstrap 10000 \
  --seed 20261022 \
  --render-per-class 1
```

输出目录必须不存在或为空。若有之前未完成的输出，保留它并换一个新目录名。显存不足时可降低 `--batch-size`，不改变本轮扰动设置或训练权重。

## 每张图做什么

对 5%、10%、20% 三个名义面积分别选择同尺寸正方形窗口：

1. **高响应窗口**：窗口内平均 Grad-CAM 值最高。
2. **低响应窗口**：窗口内平均 Grad-CAM 值最低。
3. **随机窗口**：从相同允许位置均匀抽取 20 次，先在每张图内取平均。

窗口边长按 `round(sqrt(coverage × H × W))` 取整，所以实际面积与名义面积略有差别，输出中同时记录。随机位置由图片身份和评估种子决定，在训练种子和替换方式之间共享；随机窗口允许重叠或重复，不作为独立样本。

为减少“遮组织与遮黑边”的混淆，使用独立于热图的规则识别边界连通近黑区域（亮度阈值 24/255），只允许该区域占窗口面积不超过 5% 的窗口。这只是自动边框近似，不是医生标注的解剖 ROI。输出仍记录整张图的黑边比例与黑边内热图响应比例；这轮主要分析不能评价被排除位置的依赖。

每个窗口分别采用两种处理，窗口外像素不变：

- **模糊**：用高斯模糊图的对应区域替换，核大小 31、sigma=8，仍可能保留部分结构。
- **周边均值**：用窗口外侧 8 像素环带的 RGB 均值替换。环带在图像边缘截断，排除规则黑边。若无可用环带像素，依次退回全图非黑边均值、全图均值，并记录回退原因。

全零、平坦、非有限热图、没有可用窗口以及允许窗口内响应全部相同的情况均记录原因，不用随意挑一个位置冒充有效解释。

## 主要看什么

始终跟踪**原图预测的同一个类别**，即使扰动后预测类别改变也不换目标。

`概率下降 = 原图目标类别概率 − 扰动后该类别概率`

`高响应相对随机的增量 = 高响应窗口的概率下降 − 20 个随机窗口的平均概率下降`

- 增量为正：本设置下，高响应位置对原判断的影响通常更大。
- 增量接近零：本设置下，热图排序未表现出超出随机位置的扰动效应。
- 增量为负：随机位置影响反而更大，需要检查热图或扰动方式。

同时报告高响应相对低响应的增量，以及目标类别 log-odds 的变化。后者为 `目标 logit − logsumexp(其他类别 logits)`，用于辅助观察概率接近 1 时被压缩的分数变化。

**AUC 和分类准确率不是这轮的主要验收指标。** 本轮评价热图位置排序与模型扰动响应的关系，不要求把原来约 98% 的准确率继续提高。

## 统计与输出

| 文件 | 内容 |
|---|---|
| `summary.md` | 先阅读的结果概览、可评价数量与解释范围 |
| `summary.csv` | 各面积、替换方式、训练种子的增量及患者配对区间 |
| `per_image.csv` | 所有原图的预测、热图状态、不可评价原因 |
| `perturbations.csv` | 每次扰动的位置、面积、目标类别分数变化 |
| `paired_effects.csv` | 每张图内的高响应−随机、高响应−低响应比较 |
| `window_status.csv` | 每张图、每个面积档位的窗口可评价状态及原因 |
| `metadata.json` | 输入、权重和代码校验信息、设置及是否完整结束 |
| `examples/` | 按类别和固定规则预先选择的示意图，不按效果挑图 |

区间以患者为单位成簇重采样。单种子统计使用该种子可评价图片；多种子汇总使用各个种子都可评价的共同图片集合，在该集合上共享患者抽样，并报告分母。三个种子不会变成三倍患者。区间描述这些已训练模型在当前患者上的采样变动，不包含未来训练的全部不确定性。

CSV 中概率差使用 0～1 的概率单位，例如 `0.02` 表示 2 个百分点；Markdown 概览将其乘以 100，以百分点显示。

不同面积与替换方式分开报告，不在看到结果后只留下最有利的一组。当前 val 已多次用于探索，本轮继续作为开发阶段诊断。

## 如何决定下一步

- 如果多个设置中高响应扰动均比随机扰动更有影响，支持 Grad-CAM 提供了模型依赖线索，可以进一步检查这些线索是否有医学意义。
- 如果方向随替换方式反转，或与随机位置相近，先检查输入对齐、退化热图、黑边识别和遮挡伪影，再决定是否调整解释方法。
- 第一轮数值检查可自动完成；人工只需核对示意图有无明显错位、黑边误判等。若要声称“模型依赖正确的解剖标志”，仍需医生验证。

本轮没有做参数随机化等完整解释校验，不设“通过即解释正确”的门槛，也不由此直接判定分类模型有缺陷或新增方法有效。扰动会改变输入分布；结果是对规定扰动的响应，不是解剖因果证明。

方法背景：[Grad-CAM 原论文](https://arxiv.org/abs/1610.02391)；[Sanity Checks for Saliency Maps](https://papers.neurips.cc/paper_files/paper/2018/hash/294a8ed24b1ad22ec2e7efea049b8737-Abstract.html)。
