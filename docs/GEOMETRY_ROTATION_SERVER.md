# 去暗框几何关系：完整患者轮换诊断

本轮检查：去暗框后的几何关系对分类的局部帮助，是否依赖上次恰好留出的那个患者编号。仍是静态图片三分类，不增加标签，不更换模型或教师，不训练自动筛选器。

## 这轮会做什么

5-shot中每次用4个编号准备模型，剩下1个编号检查，轮换5次；10-shot相应轮换10次。原5折共75个诊断单元：25个5-shot、50个10-shot。已有的10个单元只读复用，新运行65个。支持集合共覆盖25个文件名患者编号，75单元不是75位新患者。

每次换留出编号，都重新初始化并仅用相应A准备模型。保留已有140步分类头训练、140步几何头校准、八个辅助分支、固定更新幅度及三个对照种子。输入RGB仍有暗框，field分支仅排除涉及外围暗框的几何关系；不能称为真实深度标注。

## 1. 更新并检查

```bash
cd /opt/data/private/AirwayRecognition
conda activate airway
git pull --ff-only

bash scripts/run_geometry_rotation_server.sh check
```

| 用途 | 默认目录 |
|---|---|
| 93张原始PNG | `dataset/renew` |
| 上次已完成的10单元诊断 | `outputs/renew_geometry_diagnostic` |
| 已有教师缓存 | `outputs/renew_geometry_teacher_cache` |
| 本轮新输出 | `outputs/renew_geometry_rotation` |

注意本脚本的`--reference-root`指上次的10单元诊断目录。脚本会冻结其中339个必要文本文件，包含更早的seed42参考快照；旧结果保持原身份和原文件，不会被改写成新训练结果。已有缓存覆盖75张支持图片，无需重新生成教师缓存。

如果PNG在子目录，给check和run都加同一个`--image-root dataset/renew/气管镜`。其他路径通过`--reference-root`、`--cache-root`、`--output-root`指定。输出必须与数据、缓存和旧结果分开。

检查应识别75个计划单元、10个导入结果和65个待运行单元。新运行必须与旧10单元保持同一软件/GPU环境；遇到来源或环境不一致应先排查，不能靠删旧结果或改哈希绕过。

## 2. 后台运行新增65个单元

```bash
nohup bash scripts/run_geometry_rotation_server.sh run \
  > renew_geometry_rotation.log 2>&1 &

tail -f renew_geometry_rotation.log
```

`Ctrl+C`退出日志查看不会终止后台任务。运行时不要对同一输出启动第二个run或执行pack；完成后再检查状态。

已完成的新单元会通过核验后跳过；中断的单元归档后从头运行。每个新B均重新准备自己的模型，不复用已经看过该B的分类头。外层测试图不参与准备、几何筛选或探测。

## 3. 完成后检查和打包

```bash
bash scripts/run_geometry_rotation_server.sh status
bash scripts/run_geometry_rotation_server.sh pack
```

最终应为75/75，分别为10个旧结果和65个新结果。下载pack生成的`.tar.gz`与同名`.sha256`回传分析。包内只含文本记录、表格和参考快照，不含图片、教师NPZ或模型权重；离线核验不依赖原始数据和缓存仍在本机。

可以用`--folds`、`--budgets`限制执行。默认pack要求完整75单元；明确指定小范围打包时，包内会标记范围与整体是否完成。正式结论需要完整轮换结果。

## 如何判断是否继续

每个原折/预算分别看所有留出B的结果，不选最佳B。主要量是去暗框真实几何相对纯分类、三个打乱对照均值、三个同数量随机对照均值的B分类损失差分；正值表示相对对照更好，不是准确率百分点。

在新增65个单元运行前固定以下工程判断规则：所有计划比较都须有效；每个预算分别至少4/5个支持集，有严格多数B同时胜过纯分类和打乱均值（5-shot至少3/5个B，10-shot至少6/10个B），且该预算两项平均差分均为正，才考虑进入下一阶段方法实验。要支持“去暗框筛选有独立帮助”，还需同样多数规则下胜过同数量随机筛选，且预算平均差分为正。无效或跳过的单元不计作成功，不能从计划分母中删除。

这些是收敛研究方向的工程标准，不是统计显著性或新方法有效性的证明。已有10个结果已知，因此本轮也不是全盲验证。无论是否满足规则，都保留全部正负值、均值、中位数和波动；支持集合重叠，不能把75个单元或三个对照种子当独立患者样本。

若完整轮换仍不满足条件，结束本轮扩展并重新评估几何分支；满足条件后，也需要另行设计正式分类训练与外层评价。本轮不根据B结果自动训练门控，也不改变现有数据、标签和分类基线。
