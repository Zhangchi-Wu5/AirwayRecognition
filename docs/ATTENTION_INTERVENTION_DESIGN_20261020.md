# 固定权重的注意力空间依赖诊断设计

日期：2026-10-20。用途：检查当前注意力图是否接近常数，以及模型预测是否依赖注意力的空间分布。本文预先规定诊断方法，不包含尚未运行的服务器结果。

## 1. 背景与问题

已完成的三个训练种子（42、2026、3407）使用相同验证集：96 张图片、32 位患者。EQ 开启后有小幅分类收益，但注意力旋转误差没有一致改善；其中 3407 的注意力接近全图高响应。

当前网络的分类特征由两部分拼接而成：

- 全局分支：`mean(F)`；
- 注意力分支：`mean(F × A)`。

因此，当注意力 `A` 恒为 1 时，两部分特征相同；恒为其他常数时，注意力分支相当于全局特征乘以该常数。仅凭颜色鲜明的图或较低的旋转一致性误差，不能认定模型进行了有用的空间选择。

本次诊断回答：

1. 原始注意力值及其空间差异实际上有多大？
2. 在固定模型和输入下，移除或改变注意力的空间分布，会怎样改变分类输出？

## 2. 冻结范围

- 使用上述三个种子的 `eq_off`、`eq_on` 末轮权重，共六份模型。
- 只读取现有验证集原图；本轮不增加旋转、反光或遮挡变换，不使用测试集图像。
- 不重训、不更新 BatchNorm、不选择新的损失系数，不保存修改后的模型。
- 使用原实验的裁边及确定性评估预处理、模型结构和类别顺序。
- 不更改训练代码或模型默认前向接口。
- 只要权重、验证清单或实验配置不匹配，就应报错，不能静默视作原实验的延续。

## 3. 干预及优先级

| name | what_tests | expected_if_matters | priority |
|---|---|---|---|
| `original` | 原始注意力；分解计算路径与正常模型前向核对 | 输出在明确数值容差内一致，证明干预入口正确 | P0 |
| `mean_constant` | 每张图用自己的注意力均值填满整张注意力图，保留均值但移除空间差异 | 若空间选择参与当前预测，概率或类别可能变化 | P0 |
| `spatial_shuffle` | 对注意力空间位置作 20 次随机置换，保留全部原始数值及直方图 | 若注意力值与特征位置的对应关系重要，输出应对这种改变敏感 | P0 |
| `ones_constant` | 全部设为 1，使注意力分支成为全局特征的副本 | 用于辅助判断幅度或门控作用；其变化不能单独归因于空间位置 | P1 |

每张输入先缓存骨干特征 `F` 与原始注意力 `A`。所有干预只替换 `A`，再使用同一池化和分类头计算结果；不重跑带随机增强的输入，不更改全局分支。

`spatial_shuffle` 的位置排列由评估种子、图片稳定身份和重复编号共同确定。排列不能依赖模型名称、训练种子、批次或图片遍历顺序。对于同一图片及重复编号，三个种子和两种 EQ 设置采用同一位置排列；两模型各自的注意力数值仍然不同。

全 1 干预会改变平均幅度；等均值常数及空间置换是判断空间分布作用的主要对照。暂不增加全零、跨图交换注意力、阈值扫描或重训对照。

## 4. 图像与原始数据

保存所有验证图片在六个模型下的原始浮点注意力图及对应索引，原始分辨率为 7×7。每张图记录均值、空间标准差、最小值、最大值、分位数及归一化空间熵。

可视化要求：

- 所有图使用同一配色和固定 `[0,1]` 显示范围，显示色条。
- 禁止逐图 min-max 拉伸，禁止按单张图百分位重新定义颜色。
- 同时提供原始网格热图；叠加图的透明度固定，不能仅靠叠加图判断数值大小。
- 背景是模型实际裁边和缩放后的输入，而不是空间坐标不一致的原图。
- 放大或插值只用于显示，明确标示原始注意力为 7×7，不能当作精细解剖定位。

默认画廊按类别、再按稳定 `case_id` 排序，每类选择前三张，共九张；所有训练种子和 EQ 设置使用完全相同的图片。选择规则不读取注意力、预测、正确性或干预效果。可通过 `--render-per-class` 预先增大展示数量，包括全部图片，但不能根据效果筛选好看的示例。全部原始数值与逐图统计默认始终保存，不受画廊数量影响。

旧的 `scripts/visualize_attention.py` 使用逐图 min-max 显示且默认测试集，不适合直接作为本次诊断入口。本次使用独立脚本，避免扩大对旧展示脚本的修改范围。

## 5. 指标与统计单位

每个模型以自己的 `original` 输出作为配对参照，保存每张图片、每种干预和每次 shuffle 的完整三类概率。

主要输出：

- 原始及干预后的准确率，以及“干预后减原始”的准确率差；
- 类别翻转率；
- 真实类别概率的有符号变化；
- 概率分布 L1 变化。

辅助输出：

- 原始正确图片的正确变错误比例；
- 原始错误图片的错误变正确比例；
- 原预测类别概率下降。

跨 EQ 对比正确变错误比例时，应在每个训练种子内固定两个模型的共同原始正确队列。不得把两模型各自正确队列的差直接当作可比较的抗干预效果，也不报告未经设计支持的因果交互结论。

统计顺序固定：

1. shuffle 的重复先在同一图片内平均，再计算汇总，不能将 20 次重复当作独立病例。
2. 三个种子分别计算各自的比率，再等权平均，不把不同分母直接混合。
3. 患者成组配对 bootstrap 10,000 次：同一位患者在所有干预、模型和种子中使用相同重采样次数，保留其全部图片及 shuffle 重复。
4. 区间反映这六份固定模型在患者抽样上的不确定性，不包含未来训练种子变化。

独立患者数始终为 32；六模型、96 张图片及 20 次置换不会把它增加为更多独立患者。多个指标用于描述机制，不以挑选显著结果作为诊断目标。

## 6. 验证要求与追溯

实现至少应验证：

- 原始分解计算与模型正常前向的类别概率和 logits 在声明的容差内一致。
- identity 干预的输出差为零。
- 等均值常数保持逐图均值，空间标准差接近零。
- shuffle 后逐样本排序数值与原图完全一致；顺序、批大小和设备改变不改变定义的位置排列。
- 对常数注意力做 shuffle 不改变输出。
- 对已知依赖位置的简单模型，打乱或移除空间图案能被指标检出。
- 模型处于评估与推理模式，运行前后所有参数和缓冲区保持不变。
- 验证成员身份、实际权重哈希与原实验记录匹配；图像身份和保存的 NPZ 索引可逐项对应。
- 已存在的非空输出目录不会被覆盖；没有测试集图像加载或预测。

结果元数据应记录输入文件与权重哈希、实验来源、验证成员、干预配置、评估种子、位置排列规则、图像选择规则、软件版本及本次代码版本或源码哈希。

## 7. 能说明与不能说明

如果等均值常数和 shuffle 都几乎不改变输出，可以说当前验证输入中的注意力空间图案可被改变而预测保持稳定；不能直接说整个注意力分支没有作用。可能原因包括常数幅度作用、全局分支冗余、特征冗余或当前图片容易识别。

如果干预明显改变输出，可以说当前计算依赖注意力及空间位置的对应关系；不能据此证明模型关注正确的解剖部位。干预也可能使内部表示偏离训练分布。

有些图片在干预后可能更正确，因此必须同时报告改善与恶化，而不能把任何输出变化都称为原注意力的优势。正确的解剖定位和临床解释仍需要独立的医生区域或结构参考。

## 8. 成本与停止条件

默认只有六份模型、96 张验证图片。若每批都执行一次正常模型前向验证分解计算，则骨干计算约为 `6 × 96 × 2 = 1,152` 个图像前向；20 次 shuffle 主要增加池化和分类头计算。实际 GPU 时长应由服务器计时记录，事先不虚构 GPU 小时。

完成全部六模型的固定干预、原始图导出、配对统计和追溯核验后结束本轮。根据这批验证结果调整设计属于下一轮探索；不追加变换、阈值或筛选图片来追求更有利的结果。
