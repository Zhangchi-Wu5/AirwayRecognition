# 旋转图片上的注意力替换诊断

这一步回答：此前开启EQ后，六个旋转角度的平均准确率比关闭EQ高约0.93个百分点；把两个模型的注意力都铺平后，这个差值是否仍然存在？

使用原来的三个种子、六份末轮权重和同一验证集，不重新训练。输入先按原流程裁边、缩放和归一化，再采用此前固定的 `−15、−10、−5、0、5、10、15°`。零角度保留原张量，不插值；其他角度为固定画布的合成旋转，含双线性插值、边角裁切，归一化张量补0对应ImageNet均值颜色。

## 比较方法

每个模型对每张旋转后的图片计算自己的原始注意力，然后使用同一骨干特征和分类头分别评价：

| 模式 | 操作 |
|---|---|
| `original` | 保留该角度的原始注意力 |
| `mean_constant` | 铺平成该角度、该张图自身的注意力均值 |
| `spatial_shuffle` | 打乱该角度的49个原始注意力值，重复20次 |
| `ones_constant` | 全部设为1，注意力分支变成全局特征的副本 |

常数均值来自当前旋转后的注意力，不借用0°的均值。打乱排列按评估种子、图片身份和重复编号确定，同一图片的所有角度、EQ设置及训练种子共享排列。原始注意力值仍由各模型、各角度自行计算。

主结果是六个非零角度的等权平均，0°单独报告。先在图内平均重复，再平均角度；患者数仍为32。

## 直接看哪几个差值

对每一种注意力模式，计算：

```text
EQ增益 G = 开启EQ的准确率 − 关闭EQ的准确率

相对原始注意力的增益变化 D = 当前模式的G − original模式的G
```

例如，若本轮原始增益为+0.93个百分点，铺平后的增益为+0.90个百分点，则增益变化为−0.03个百分点；若铺平后增益变为0，则增益变化为−0.93个百分点。这里只是解释计算方式的假设例子，不是新实验结果。

两个模型各自的准确率和干预后变化也必须一起看。若它们都下降了相同幅度，EQ差值可以保持不变，但不能据此说注意力没有作用。

另外报告：

```text
旋转与原图的EQ增益差 R = 六个非零角度的G − 0°的G
```

R用于区分旋转后总准确率优势和原图上已有的优势，是描述性差值，不是已经证明的因果机制。患者区间直接对同一次重采样里的差值计算，不通过相减两条独立置信区间得到。

## 服务器运行

在代码同步后执行：

```bash
cd /opt/data/private/AirwayRecognition
conda activate airway
git pull --ff-only

python -u -m scripts.diagnose_rotation_attention \
  --run-dirs \
    rotation_ablation_v1/seed_42 \
    rotation_ablation_v1_more_seeds/seed_2026 \
    rotation_ablation_v1_more_seeds/seed_3407 \
  --splits-dir data_splits_patent \
  --image-root dataset \
  --output-dir rotation_attention_diagnostics_v1 \
  --device cuda \
  --batch-size 16 \
  --shuffles 20 \
  --bootstrap 10000 \
  --seed 20261020
```

若训练目录曾改名，只修改 `--run-dirs` 后的路径。需要保留每组的 `pair_metadata.json`、两个模型的 `run_config.json` 和 `last_model.pt`。脚本校验权重、验证清单、训练配对和核心源码，包括旋转实现；不使用按验证成绩挑选的权重。

角度在本轮固定，没有额外角度扫描选项。输出目录必须为空或不存在，已有结果不会被覆盖。

## 输出与核验

| 文件 | 内容 |
|---|---|
| `summary.md` | 直接阅读的汇总，包含两模型成绩、EQ增益及增益变化 |
| `eq_gain_summary.csv` | 各种子、各模式的G、D和R及患者区间 |
| `eq_gain_combined.csv` | 三种子等权平均的G、D和R、种子标准差及患者区间 |
| `model_summary.csv` | 各种子、模型和模式的准确率与干预影响 |
| `model_combined.csv` | 上述模型指标的三种子汇总 |
| `per_image_predictions.csv` | 所有角度、干预和重复的完整三类概率 |
| `attention_stats.csv` | 各模型、图片、角度的原始注意力分布统计 |
| `seed_*/raw_maps/` | 所有角度的原生7×7图，含图片和角度索引 |
| `metadata.json`、`seed_*/metadata.json` | 参数、来源、前向一致性、状态未变和历史结果对照记录 |

默认生成92,736行预测；它们仍然只来自同一批96张图、32位患者。`scope=nonzero_mean`为主比较，`scope=angle`为各角度分解。

预测表里的 `original_*` 指**同一角度下、原始注意力**的输出，因此其中的翻转和概率变化表示注意力干预的影响，不是相对于0°的输入旋转影响。

每个批次的每个角度都会核对诊断计算与正常模型前向一致；推理前后检查权重及缓冲区没有变化。若训练目录下保留了 `rotation_val/per_image_predictions.csv`，还会对照原始注意力组的历史预测，记录类别一致率和概率差；没有该文件则明确记录未对照。批大小等数值因素可能带来微小概率差异，本轮差值始终用本轮重新计算的原始组，不硬编码旧结果的0.93。

置信区间按患者共同重采样，同一位患者在所有种子和干预中的样本同时保留；区间条件于已有六份模型，种子间波动另列标准差。区间包含0不能证明等价，也不能自动宣布收益“全部保留”；不报告容易受小分母影响的收益保留百分比。

## 结果怎样解释

- **铺平后EQ增益仍相近：**提示这批旋转图上的增益不必依赖推理时的注意力空间差异，需结合两模型各自的准确率变化判断。
- **铺平后EQ增益明显缩小：**提示原始空间配置可能参与该差异，但还需排除分支冗余、内部干预偏离训练分布等解释，不能直接证明正确解剖定位。
- **只有全1结果改变：**全1同时改变平均幅度，不能单独归因于空间位置。
- **区间较宽或不同种子方向相反：**结论是不确定，不增加种子、角度或筛选病例来追求有利结果。

无论结果如何，本实验都不能代替“训练时移除注意力”的重训消融，也不能证明临床解释质量。
