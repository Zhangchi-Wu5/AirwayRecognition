# ResNet 小样本实验：全部在服务器运行

这是本轮推荐流程：本地维护与版本管理代码，服务器在同一环境中依次运行冻结线性探测和整体微调，最后将一个结果包拉回本地统一分析。本地已有的冻结结果保留为先前探索，不混入这次服务器的主比较。

## 代码同步

本地将本轮源码、测试、依赖与文档作为一次独立 Git 提交推送。只提交实验工具，不提交图片、权重、特征缓存、逐图预测或其他研究任务的修改。

推送完成后，在服务器执行：

```bash
cd /opt/data/private/AirwayRecognition
git status --short
git pull --ff-only
conda activate airway
nvidia-smi
```

本流程直接在服务器原项目目录运行，不需要上传旧的独立微调压缩包，也不需要进入 `fewshot_server_20261022` 子目录。使用仓库内已有的 `data_splits/`，通过 `dataset/` 重定位图片路径；不重新划分患者。

运行期间保留同一份源码，避免继续拉取修改导致恢复时的来源校验不一致。运行记录会保存代码指纹、Git 版本、依赖和数据指纹。

## 检查并启动

确认 0 号 GPU 空闲后执行；使用其他空闲卡时修改编号：

```bash
CUDA_VISIBLE_DEVICES=0 bash scripts/run_fewshot_suite_server.sh check
```

检查成功后开始后台运行：

```bash
CUDA_VISIBLE_DEVICES=0 nohup bash scripts/run_fewshot_suite_server.sh run \
  > fewshot_suite.log 2>&1 &
tail -f fewshot_suite.log
```

`Ctrl+C` 退出日志查看，不会停止后台训练。任务中断后，用相同配置重新执行 `run`；日志建议换一个文件名以保留先前日志。不要同时启动两个指向相同结果目录的任务。

默认结果根目录为 `outputs/resnet_fewshot_suite_20261022`，默认 CUDA、batch16、workers4。需要指定不同数据位置时，给 `check`、`run` 和 `pack` 一致追加参数，例如：

```bash
bash scripts/run_fewshot_suite_server.sh check \
  --splits-dir data_splits --image-root /实际图片目录 \
  --output-root outputs/resnet_fewshot_suite_new
```

批量大小和训练配置一经开始即固定；需要改变时使用新的结果目录。

## 自动执行内容

| 阶段 | 子目录 | 内容 |
|---|---|---|
| 冻结特征 | `frozen/` | 每类1/5/10/20张各20次，加全量一次，共81个线性头 |
| 流程检查 | `smoke/` | 一份支持集、4次微调更新；不计入正式结果 |
| 整体微调 | `finetune/` | 复用本次服务器冻结实验的81份支持集，逐组重新初始化与训练 |

正式比较共162次拟合。两种方法在相同服务器环境、相同患者划分及支持集上评价；全部使用固定验证患者，测试图片不读取。

微调默认先训练分类头140步，再整体微调560步。每次更新16张，小样本重复洗牌补满批次；固定BN运行统计，不做左右翻转，使用最后一轮模型。该比较包含整个适配流程的差异，不是单独检验“是否解冻主干”。

均值和标准差描述选择不同训练患者引起的变化，不能当作新验证患者的置信区间。全量每种方法各运行一次；训练优化种子固定，尚未估计多优化种子波动。

默认需要保留约8GB微调权重，建议至少10GB可用磁盘并预留数小时运行窗口。耗时取决于GPU和图片读取速度，本轮服务器耗时尚未实测。

## 中断与恢复

已完成的冻结阶段仅在数据、源码、配置与产物校验通过后复用。未完成的冻结尝试保留在 `incomplete_attempts/` 后重新运行。微调保留已完成并通过校验的支持集，中断的一组从官方初始权重重新训练，不从组内某一步恢复。

已完成文件损坏或配置变化时会拒绝继续，不能把残缺结果视为完成。旧的本地冻结结果不会自动替换本次服务器参考。

恢复还会核对 Python、依赖库和 CUDA 版本，避免两阶段或不同支持集混用变化后的环境。GPU 信息另外保存在运行记录中。

## 统一拉回结果

两阶段全部完成后执行：

```bash
bash scripts/run_fewshot_suite_server.sh pack
```

默认生成：

```text
outputs/resnet_fewshot_suite_20261022_results.tar.gz
```

下载这一份压缩包回本地即可。包内保留两个阶段的报告、曲线、逐图预测、支持集、协议与日志；排除体积较大的微调权重，原权重继续保存在服务器。未完成的实验不会被打包成完整结果。

同目录还会生成 `.tar.gz.sha256` 校验文件；打包前会核对正式汇总报告、表格与曲线的完整性。

正式分析首先比较各方法内部小样本与全量的差距，再比较同一支持集下微调相对于冻结的差值。不会把本地探索结果与服务器微调结果混成同一条学习曲线。
