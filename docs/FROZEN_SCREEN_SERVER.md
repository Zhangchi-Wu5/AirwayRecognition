# 冻结 ResNet-18 特征与训练患者抽样筛查

这轮实验用于定位问题：固定的预训练特征能否完成当前三分类，以及更换5位训练患者会让成绩波动多大。它包含实际分类与留出评价，属于研究方向筛查；目前不提出新的专利算法，也不自动进入后续选样研究。

## 固定方案

使用当前已核验的93张静态图像、31位患者，沿用患者隔离的五折。每个患者三类各一张；每次选择5位训练患者，即每类5张、共15张。外层留出患者不参与分类器拟合、调参或支持集选择。

1. 使用 ImageNet 预训练的 `ResNet18_Weights.IMAGENET1K_V1`，对每张图片提取一次512维特征。主干所有参数和BN统计均冻结，保持评价模式；沿用现有 `full_frame` 确定性评价预处理，无随机增强。每张图单独进行L2归一化，不在全队列上拟合标准化、PCA或其他变换。
2. 在原来的 `repeat 0` 支持集上比较两个分类器：最近类别原型、带L2正则的多项逻辑回归。前者使用训练样本的同类均值，归一化后按余弦相似度分类；概率采用固定温度1的softmax。后者只在被选5位患者内进行留一患者验证，从预定的 `C = 0.1, 1, 10` 中按平均验证交叉熵选参，再用全部15张支持图拟合。不会根据外层成绩扩展参数范围。
3. 在看到结果之前生成100套患者抽样清单；每套、每折均从该折训练池均匀选5位不同患者，两个分类器共享清单。原支持集作为独立参考，不混入100套分布。

共计 `(1套参考 + 100套抽样) × 5折 × 2个分类器 = 1010个最终分类任务`。其中505个逻辑回归任务各包含15次内部验证拟合和1次最终拟合；其余505个任务只计算类别原型。这些任务使用缓存特征，不是1010次神经网络训练。特征提取使用GPU，分类器在CPU上拟合；实际耗时由服务器日志记录。

两种分类器输出的概率形成方式不同，主比较看正确数、准确率、macro-F1和逐类召回；AUC与交叉熵作为补充，不把原型的温度1概率当作已校准置信度。

逻辑回归固定使用 `lbfgs`、容差 `1e-8`、最多10000次迭代；内部平均损失相差不超过 `1e-12` 时选择较小C。未收敛直接报错，不保存为成功结果。小模型计算固定为单线程，环境和数值库版本记录在结果中。

## 在服务器运行

沿用 `airway` 环境，先拉取代码：

```bash
cd /opt/data/private/AirwayRecognition
git pull --ff-only
```

先核对数据并保存完整固定计划：

```bash
bash scripts/run_frozen_screen_server.sh check \
  --image-root dataset/renew \
  --output-root outputs/renew_frozen_screen
```

`--image-root`必须直接包含93张PNG。如果此前用的是 `dataset/renew/气管镜`，在检查和运行命令中都沿用该路径。检查阶段不会提取特征，也不会下载预训练权重。

检查通过后后台运行：

```bash
nohup bash scripts/run_frozen_screen_server.sh run \
  --image-root dataset/renew \
  --output-root outputs/renew_frozen_screen \
  > renew_frozen_screen.log 2>&1 < /dev/null &
```

查看进度：

```bash
tail -f renew_frozen_screen.log
```

`Ctrl+C`只退出日志查看。首次提取特征可能下载官方预训练权重；已有几何教师缓存不参与本实验。运行中断后，在代码、数据和环境不变的情况下重复相同命令，脚本核验后跳过完成任务。使用同一个输出目录时不要修改方案或覆盖缓存。

默认以CUDA提取；如明确需要CPU提取，可以在运行时指定 `--device cpu`，须使用独立输出目录并在后续运行时保持同一设备设置。

也可以用 `--phase reference` 先完成原支持集，之后用 `--phase draws` 完成固定的100套抽样；它们仅筛选完整计划中的任务，不改变方案。最终判断和正式打包须等待全部任务完成。

## 完成后打包回传

```bash
bash scripts/run_frozen_screen_server.sh status \
  --output-root outputs/renew_frozen_screen

bash scripts/run_frozen_screen_server.sh pack \
  --output-root outputs/renew_frozen_screen
```

取回打印出的 `.tar.gz` 和 `.sha256` 文件。状态核验与打包使用保存的结果，不需要原始图片或GPU。结果包保存方案、特征来源及校验记录、患者抽样清单、内部调参记录、分类器参数、逐图预测和统计表；原始图片、ResNet权重以及特征矩阵留在服务器。包内仍有患者编号和研究结果，应保留在项目研究环境中，不上传公共Git仓库。

正式汇总包括原支持集的两组结果、100套抽样的均值/标准差/分位数、同抽样下两个分类器的差异，以及每张图片在100套抽样中的错误频率。不会输出按测试成绩推荐的“最佳5位患者”。

## 结果如何指导下一步

| 观察 | 下一步判断 |
|---|---|
| 同支持集上冻结分类器已接近或超过全微调 | 保留更强基线，再判断是否需要有限适配 |
| 换训练患者导致较大波动 | 才考虑患者成组选样候选，并另行固定公平对照 |
| 多数抽样下简单分类器已经很强 | 不人为降低基线；需要新的实际功能目标或验证数据 |
| 固定特征普遍较弱 | 结合已有全微调结果，研究特征适配；不直接归因于数据无法学习 |

100套抽样重复使用同一31位患者，不能当作100次独立临床验证；分位数描述支持抽样波动，不是外部泛化性能的置信区间。冻结分类器的波动也不能直接代表全微调模型的波动。已有全微调CE只能与相同原支持集作对应比较，不能与100套新抽样的均值当作配对实验。当前队列已用于多轮探索，本轮仍属于开发性分析。
