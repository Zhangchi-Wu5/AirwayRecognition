# 注意力原值导出与固定模型替换诊断

这一步使用已有旋转消融实验的六份 `last_model.pt` 权重，检查两个问题：注意力图是否接近全图高响应，以及模型预测是否依赖注意力的空间位置。无需重新训练或新增标注，沿用已有验证集原图。

## 做哪四种比较

| 模式 | 操作 | 回答的问题 |
|---|---|---|
| `original` | 保留模型自己计算的注意力 | 原始参照；同时核验诊断计算与正常模型前向一致 |
| `mean_constant` | 把注意力铺平成该图的平均值 | 保留平均幅度，去掉空间差异后，预测是否改变 |
| `spatial_shuffle` | 将原生7×7注意力的49个值打乱位置，固定重复20次 | 保留全部数值，破坏位置对应后，预测是否改变 |
| `ones_constant` | 将注意力全部设成1 | 辅助检查整体幅度；此时注意力分支成为全局特征的副本 |

仅替换同一模型的注意力值。输入、骨干特征、全局分支、分类头和权重保持不变。模型使用评价模式；运行前后核对参数及缓冲区不变。每个批次还会用正常模型前向核验原始输出，防止诊断代码悄悄改变模型计算。

这一版只检查验证集原图上的注意力依赖，不额外加入旋转。先把空间注意力本身的作用查清，再决定是否扩展诊断。

## 服务器执行

将本轮代码同步到服务器后，在项目目录、原有 `airway` 环境下运行：

```bash
cd /opt/data/private/AirwayRecognition
conda activate airway

python -u -m scripts.diagnose_attention \
  --run-dirs \
    rotation_ablation_v1/seed_42 \
    rotation_ablation_v1_more_seeds/seed_2026 \
    rotation_ablation_v1_more_seeds/seed_3407 \
  --splits-dir data_splits_patent \
  --image-root dataset \
  --output-dir attention_diagnostics_v1 \
  --device cuda \
  --batch-size 16 \
  --shuffles 20 \
  --bootstrap 10000 \
  --seed 20261020 \
  --render-per-class 3
```

请保留各训练目录内的 `run_config.json`、`pair_metadata.json` 和末轮权重，脚本会核对权重与验证集的哈希、同一对模型的训练记录，以及跨种子的共同设置。模型和预处理核心源码也必须与训练时一致。

若部分目录改过名字，只需修改 `--run-dirs` 后的路径；不要用 `best_val.pt` 替换末轮权重。输出目录必须不存在或为空，已有结果不会被覆盖。

## 注意力图怎样导出

- 全部验证图片、全部六个模型均保存原生7×7浮点注意力值和逐图统计，不只保存展示图片。
- 逐图统计包括均值、空间标准差、最小值、最大值、分位数和归一化空间熵。
- 默认每类按稳定的图片标识排序选前3张作图，共9张；同一组图片用于所有种子和两种模型。选图不看预测是否正确或热图是否好看。
- 每张展示图并排显示实际模型输入、关闭/开启EQ的原生注意力及叠加图；全部图固定色阶0–1，附色条。
- 原生7×7格子图不做逐图对比度拉伸；叠加图的放大只是显示处理，不代表定位分辨率提高。

如需把目前每类32张都渲染成图片，可在首次执行时将 `--render-per-class 3` 改为 `--render-per-class 32`。两种设置都会保存全部原始注意力数值，区别仅在展示图片数量。若已有输出目录，请换新目录名再运行。

旧的 `scripts/visualize_attention.py` 会逐图拉伸颜色，本次诊断使用新的独立入口，以便识别接近常数的图。

## 看哪些结果

输出目录包含：

| 文件或目录 | 内容 |
|---|---|
| `summary.md` | 直接阅读的汇总报告 |
| `intervention_summary.csv` | 每个训练种子、每个模型的干预指标和患者区间 |
| `intervention_combined.csv` | 三个种子的等权均值、种子间标准差和患者区间 |
| `per_image_predictions.csv` | 全部逐图、逐次干预的三类概率与预测 |
| `attention_stats.csv` | 全部原始注意力图的逐图分布统计 |
| `seed_*/raw_maps/eq_off.npz`、`eq_on.npz` | 全部原生7×7浮点注意力图及对应图片标识 |
| `seed_*/figures/` | 关闭/开启EQ的配对展示图 |
| `metadata.json`、`seed_*/metadata.json` | 参数、来源哈希、前向一致性和权重未变核验 |

每个种子目录还保留自身的逐图预测与注意力统计。默认96张图、3个种子、2个模型和20次打乱会产生13,248行预测；独立图片仍是96张。

优先比较每个模型的干预结果与其自身 `original`：

- 准确率差：替换后的准确率减原始准确率。
- 类别翻转、原本正确变错误、原本错误变正确。
- 真实类别概率变化、原预测类别概率下降、完整三类概率的L1变化。
- 注意力本身的改动幅度：若原图已很均匀，打乱造成的输入变化也会很小。

`mean_constant` 和 `spatial_shuffle` 是检查空间选择性的主要对照；`ones_constant` 同时改变平均幅度，单独变化不能证明位置重要。

20次打乱先在每张图内汇总，再按患者计算区间；它们不是20份独立样本。所有模型和种子共用患者重采样，跨种子先计算各自比率，再等权平均。独立患者数仍为32。

患者区间以这六份已训练权重为条件，不包含换训练种子的额外不确定性；种子间变化另看标准差。原本错误图片可能很少，对应“错误变正确率”的区间应连同分母和有效重采样次数一起看；分母为零时显示NA。

各模型自身“原本正确”队列可能不同。跨EQ比较变错率时使用两模型共同原图正确队列，不把不同分母的自身变错率直接相减解释成EQ的因果作用。

## 如何解释

- **替换后几乎不变：**当前验证图片上，改变空间图案未明显影响输出。可能存在全局分支补偿、特征冗余或注意力主要调节幅度，不能直接推断整个注意力分支没有作用。
- **替换后明显改变：**说明预测在计算上依赖注意力，但仍不能证明关注的位置是正确解剖结构。
- **只有全1替换有影响：**应先考虑平均幅度变化，结合等均值常数对照判断。
- **热图接近全亮且打乱影响小：**支持进一步检查空间选择性不足，但不要仅凭事后阈值自动宣布注意力“塌缩”。

当前没有医生区域标注，因此本实验不输出“解剖定位准确率”，也不自动给出可解释性或临床有效性的结论。固定模型干预也可能产生训练中未见过的组合，其影响不等同于某模块重训后的贡献。
