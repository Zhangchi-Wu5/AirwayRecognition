# 从训练开始学习／固定注意力：匹配对照

状态：已确定实验设计；实际患者数据的训练结果待服务器运行。此文档不报告新方案效果。

## 要回答的问题

保持 ResNet-50 骨干、全局／注意力特征拼接分类头、裁边、增强和训练预算一致，允许空间注意力学习，是否比始终使用均匀权重带来分类收益？

这与此前“训练完成后替换注意力图”的诊断不同：本次从初始化开始训练两组模型。固定组保留相同的拼接分类头和 dropout，因此不能称为普通 ResNet 基线。

## 组别与损失

| 组名 | 注意力 | 分类损失 | EQ 权重 | 高光抑制 PF 权重 | 用途 |
|---|---|---|---:|---:|---|
| `fixed_ce` | 始终固定为 0.5 | 有 | 0 | 0 | 主对照 |
| `learned_ce` | 从 0.5 开始学习 | 有 | 0 | 0 | 主实验 |
| `learned_regularized` | 从 0.5 开始学习 | 有 | 0.1 | 0.1 | 可选联合正则对照 |

默认只训练前两组，主差值方向为 `learned_ce − fixed_ce`。使用 `--include-regularized` 才训练第三组，额外比较 `learned_regularized − learned_ce`；这项比较同时改变 EQ 和 PF，只能解释为联合正则作用，不能当成单独 EQ 的作用。

固定注意力的 EQ 误差近乎平凡，PF 值则主要对应高光掩膜面积比例，二者都不能体现学习到了合理的解剖关注。故主对照两组同时关闭 EQ、PF，避免把“允许学习注意力”与“新增正则损失”混在一起。固定组的低 EQ 误差不是有利的研究结果。

## 如何匹配

- 两组均将注意力卷积权重初始化为零，经过 sigmoid 得到全图 0.5；骨干、分类头及全部参数／缓冲区初值相同。固定组始终冻结该卷积，学习组允许它更新。
- 阶段一冻结骨干、训练分类头及允许学习的注意力；阶段二解冻骨干，但固定组的注意力继续冻结。
- 固定组的特征为 `[全局特征, 0.5 × 全局特征]`。保留与学习组相同的 4096 维拼接头，避免同时改变分类头规模；本实验不比较推理速度。
- 默认固定训练 5+20 轮，以 `last_model.pt` 为主检查点。最佳验证权重仅作追溯，不能看结果后替换主检查点。
- 两组每个训练批次都执行主图和旋转图的前向计算，零权重组仍保留辅助计算，以匹配 BatchNorm 更新次数和 dropout／旋转随机数消耗。
- 使用相同训练种子、数据顺序、增强流、批大小与优化设置，记录初始化、输入流、运行配置及检查点哈希。
- BatchNorm 的训练模式和调用次数相同；模型学习轨迹分化后，运行均值和方差可以不同，不要求数值保持一致。
- 新实验采用零初始化注意力，与历史随机初始化的模型不同。历史结果不能直接充当本轮的某个对照组。

## 在服务器运行

将本次新增代码同步到服务器后，在现有环境运行。使用已有患者划分，不重新生成划分。

```bash
cd /opt/data/private/AirwayRecognition
conda activate airway

python -u -m scripts.run_attention_training_ablation \
  --splits-dir data_splits_patent \
  --image-root dataset \
  --output-root attention_training_ablation_v1 \
  --seeds 42 2026 3407 \
  --device cuda \
  --batch-size 32 \
  --num-workers 4 \
  --bootstrap 10000
```

默认共训练 6 个模型，每个种子 2 个；完成后自动进行验证集配对评价。运行时间以服务器实测为准。

如在开跑前决定同时检验联合正则，可在上述命令增加 `--include-regularized`，并将输出目录改为 `attention_training_ablation_with_reg_v1`，共训练 9 个模型。两组主对照的设置保持不变。

输出目录必须不存在或为空。重跑使用新目录，避免覆盖历史实验；该入口不从半途检查点恢复。

每个种子的模型、训练记录和检查点保存在 `seed_42/fixed_ce/`、`seed_42/learned_ce/` 等目录；配对评价保存在 `seed_42/attention_training_val/`，其他种子结构相同。其中：

- `per_image_predictions.csv`：逐图、逐角度、逐模型的预测和概率。
- `summary.csv`、`paired_comparison.csv`、`summary.md`：该种子的汇总、差值及患者区间。
- `metadata.json`：评价设置及训练来源核验记录。

当前入口输出各个种子的结果。回传后再对预定三个种子统一计算等权均值、种子标准差和共同患者重采样区间，不将某一个种子的区间当作三种子总体区间。

## 评价与判读

仅对验证图像推理；测试集只读取成员信息核查患者隔离，不加载测试影像。

评价固定角度为 −15、−10、−5、0、5、10、15°。主结果是六个非零角度的图内均值，再按图片汇总；同时单独报告 0°。这是一项合成小角度旋转评价，含插值和边缘裁切，不能直接外推真实镜头运动。

保留以下结果：

- 各组准确率、分类别召回率、旋转前后预测翻转率。
- 两模型在原图上都正确的同一队列，其正确变错误比例。
- 真实类别概率变化及完整类别概率分布的变化。
- 配对患者 bootstrap 区间、逐图概率及注意力分布统计。

共同正确队列按每一项模型配对分别定义，不把不同配对的比例直接相减作为因果交互效应。重复角度和训练种子不增加独立患者数，患者区间也不能替代训练种子不确定性。

训练日志中的 `eq_loss` 是辅助计算得到的原始值；只有对应权重大于零时才影响训练目标。主对照未计算 PF，日志 `pf_loss=0` 表示该项关闭，不能解释为高光抑制已经理想。

如果学习组优于固定组，只能说明在这个初始化、分类头、训练流程和数据范围内，允许学习注意力有增量价值。学习会同时改变空间布局和平均幅度，本对照不能进一步拆分这两项作用，也不自动证明空间定位符合解剖结构。如果相近或更差，也应完整保留结果，不据此挑换种子、检查点或角度。

已反复查看的患者数据用于探索。新增设计的最终效果仍应在未参与设计选择的患者上确认。
