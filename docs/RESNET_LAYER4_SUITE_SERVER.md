# ResNet layer4＋分类头：服务器配对比较

本轮仍使用ResNet-50。few-shot描述标注预算，微调描述可训练参数；之前已经完成的是“少量标注＋整体微调”，现在比较“同样少量标注＋部分微调”。整体微调不代表使用全部训练图片：5-shot仍只有15张标注图，10-shot仍只有30张。

| 内容 | 已完成主基线 | 本轮候选 |
|---|---|---|
| 骨干与初始化 | ImageNetV2 ResNet-50，seed42 | 相同，核对初始状态指纹 |
| 每类标注 | 5张、10张，各20份既有支持集 | 同一支持集逐组配对 |
| 第一阶段 | 只训练分类头，140次更新 | 相同 |
| 第二阶段 | 整个主干和分类头，560次更新 | 仅整个layer4和分类头，560次更新 |
| BN运行统计 | 固定 | 固定 |
| 最终评价 | 最后一次更新后的模型 | 相同 |
| 本轮操作 | 核验后引用40组原结果 | 新增40次训练 |

`layer4`是最后一个完整残差阶段，不是第四个卷积层，也不是ViT。候选只是标准部分微调策略，不预先称为算法创新。当前首轮固定seed42，只比较这两个预算；没有自动增加其他方法或训练种子。

## 1. 更新和检查

在原服务器项目目录执行：

```bash
cd /opt/data/private/AirwayRecognition
git status --short
git pull --ff-only
conda activate airway
nvidia-smi
```

遇到Git本地修改冲突时先保留并核对，不强制覆盖。沿用上一轮环境，不主动升级依赖。确认0号GPU空闲后执行：

```bash
CUDA_VISIBLE_DEVICES=0 bash scripts/run_layer4_suite_server.sh check
```

默认读取`data_splits/`、`dataset/`以及原服务器`outputs/resnet_fewshot_suite_20261022`。需要的是原few-shot套件，不是刚刚返回的全量复现包。检查会核对原支持集、整体微调结果、图片与源码来源，以及运行环境；不会重划患者或重抽支持集。

## 2. 启动

检查通过后执行：

```bash
CUDA_VISIBLE_DEVICES=0 nohup bash scripts/run_layer4_suite_server.sh run \
  > layer4_suite.log 2>&1 &
tail -f layer4_suite.log
```

`Ctrl+C`只退出日志查看。默认输出目录为`outputs/resnet_layer4_suite_20261022`。中断后用同样参数再次执行`run`；建议换日志名保留旧日志。已完成且核验通过的组会复用，中断的一组归档后重新初始化训练。

上一轮相应40组整体微调的训练循环合计约81.5分钟。本轮部分微调尚未实测；建议先预留1.5—2小时和至少5GB磁盘，不以预估耗时作为完成判据。

若路径不同，使用`--splits-dir`、`--image-root`、`--reference-root`和`--output-root`指定实际位置，`check`与`run`保持相同参数。不要在训练中修改代码或环境，也不要向同一结果目录并发启动两个任务。

## 3. 打包回传

全部完成后执行：

```bash
bash scripts/run_layer4_suite_server.sh pack
```

下载：

```text
outputs/resnet_layer4_suite_20261022_results.tar.gz
outputs/resnet_layer4_suite_20261022_results.tar.gz.sha256
```

权重留在服务器；包内保留候选与引用基线的逐图预测、支持集、指标、配置和来源证据。打包可离线执行，不需要CUDA或原图片；恢复训练则需要保留完整权重。若使用非默认输出目录，打包时也指定相同`--output-root`。

## 4. 怎样判断结果

主要指标为accuracy，macro-F1及各类召回作为次要指标。分别报告5/10-shot下20份支持集的均值、样本标准差，以及同支持集候选减基线的配对差与胜/平/负。单训练种子的抽样SD不代表优化随机性，也不是患者泛化置信区间。

结果很好时，将部分微调升级为强基线，再检查收益是否跨支持集、训练种子和患者成立；不为了制造改进空间而撤掉强基线。若常规方法已满足事先明确的实际需求，可以接受简单方法，也可以在有真实需求时研究新的患者、设备或困难条件；不会仅因一次高分自动换方向。

结果一般或更差时同样保留全部40组，不挑有利支持集、不更换最好checkpoint、不把效果归因于未检验机制。本轮不自动追加调参、多种子或新方法。

训练和推理会检查冻结区域不变、layer4与分类头更新、BN统计不变、初始化一致及checkpoint重载。原整体微调没有保存完整逐批增强指纹；复用不等于独立重新观测历史输入流，报告不能虚构此证据。

本轮只使用固定验证患者评价，不访问测试图像；这描述本轮执行范围，不表示项目历史测试集从未被查看。后续确认性评价需使用与方法选择隔离的患者数据。
