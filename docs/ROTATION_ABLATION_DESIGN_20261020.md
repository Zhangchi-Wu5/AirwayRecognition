# 旋转等变约束的最小受控诊断

日期：2026-10-20。状态：实验设计，尚无这组新实验的结果。目标是检查现有 EQ 约束的作用，不把消融实验本身称作新的专利创新。

## 要回答的问题

在裁边、注意力结构、高光约束、普通旋转增强和训练预算相同的情况下，加入 EQ 损失梯度，是否让同一张气管镜图在小角度旋转后保持更好的分类表现，同时让注意力随图像旋转且不退化？

当前普通 ResNet 与完整方案的比较同时改变结构、裁边和训练过程，不能单独归因到 EQ。当前训练代码在 `lambda_eq=0` 时还会跳过一次旋转前向计算：它同时改变 BatchNorm 的更新次数和随机数消耗。因此，只改这一个数值而不匹配计算路径，不足以隔离 EQ 损失的作用。

## 最小两组

| name | what_it_tests | expected_if_component_matters | priority |
|---|---|---|---|
| `eq_sham`：裁边 + 原有注意力 + PF=0.1；执行旋转分支，但 EQ 权重为 0 | 为 EQ 损失提供匹配的对照；同样消耗旋转与 dropout 随机数，同样执行额外 BN 前向更新 | 提供相同结构、增强与计算路径下的参照 | 1 |
| `eq_on`：上述设置不变，EQ 权重为 0.1 | EQ 梯度是否产生超出普通旋转增强的增量效果 | 旋转后的准确率更高、共同正确变错率更低，注意力等变误差下降且不是通过趋于常数或全低值实现 | 1 |
| 可选 `eq_absent`：与 `eq_sham` 相同，但不执行旋转分支 | 额外旋转前向及其 BN 更新本身是否影响结果 | 若它与 `eq_sham` 不同，说明完整实现的影响不能全部归因于 EQ 梯度 | 3，首轮不运行 |

`eq_sham` 是控制计算路径的诊断对照，不是声称生产环境需要保留无效计算。两组都沿用现有训练增强中的 ±15° 随机旋转，因此本实验不比较“有无旋转增强”。

## 训练控制

1. 读取服务器已有划分，禁止重新划分或覆盖 `data_splits_patent`。训练只读 `train.csv` 对应图像；评价只读 `val.csv` 对应图像。检查患者隔离，保留划分文件哈希。可读取测试集的成员信息进行隔离核验，但不加载测试图像或生成新的测试预测。
2. 两组都使用普通分辨率的 attention ResNet50、裁边、`specular_highlight` PF 掩膜、PF=0.1、dropout=0.3、EQ 最大训练角度 15°，保留现有阶段 1 冻结参数与阶段 2 解冻行为。
3. 每个训练种子在建模前重新设置 Python、NumPy、PyTorch CPU/CUDA 随机种子；每组使用独立但同种子的 DataLoader generator 和相同 worker 设置。核对初始化状态哈希相同。
4. 两组始终执行相同的主图和旋转图 forward；零权重组仍将 `0 * eq_loss` 接入总损失，避免跳过旋转、dropout 或 BN。不要一组使用 `no_grad`、另一组带梯度，或只冻结其中一组 BN。
5. 固定训练预算为阶段 1 的 5 轮加阶段 2 的 20 轮。早停耐心设置大于阶段 2 轮数，确保不会提前退出。主分析使用固定训练结束时的模型。可另外保存最佳验证准确率权重供追溯，但不能看旋转结果后再挑一个检查点作为主分析。
6. 固定学习率、权重衰减、优化器、调度器、批大小和数据增强，不进行参数搜索。新输出单独保存，禁止覆盖历史实验。
7. 记录配置、代码版本、划分与权重哈希、实际轮数、输入顺序与增强的核验信息、训练日志。相同软件和设备上应能匹配随机路径；不承诺跨软硬件的位级一致。

两组参数因 EQ 梯度逐步分化后，BN 统计量也可能分化，这是训练效应的一部分。需要控制的是相同初始条件与调用策略，不能要求不同权重轨迹下 BN 数值永远相同。本诊断不冻结 BN，也不采用 BN 重校准，因此不能据此声称修复了历史模型的 BN 问题。

## 验证方案

仅使用既有验证集，固定角度 `0, -5, +5, -10, +10, -15, +15` 度，两个模型对每图使用完全相同的输入与变换。

主实验复用现有 `_rotate` 的双线性旋转和固定画布。输入已经归一化，旋转补入的 0 对应 ImageNet 均值色，不是 RGB 黑色。旋转包括插值与边角裁切，因此应称“合成小角度旋转诊断”，不能直接外推为真实镜头运动或所有方向变化。

### 分类指标

预先指定非零六个角度等权平均的**准确率差**和**共同干净正确变错率差**作为主要判断量，再展示逐角度结果：

- 原图及各旋转角度的绝对准确率、分类别召回率。
- 全部图的预测翻转率，以及错误变正确比例；低翻转率可能只是稳定地预测错误。
- 共同干净正确队列：同一训练种子的两组模型在 0° 下均正确的图像；两个模型在这个相同队列上计算正确变错误比例。不得把各自不同的干净正确队列混用于直接比较。
- 真实类别概率变化 `p_rot(true) - p_clean(true)`；若报告“下降”，明确其为相反符号的有符号量，不能截断负值。
- 三类概率分布的 L1 变化，作为辅助描述。

按患者成组配对 bootstrap；每次保留该患者所有图像和所有角度，再计算两组差值。多角度、同图、同患者以及重复训练种子都不增加独立患者数。三个种子的描述统计和固定种子患者区间分开解释，不把一组患者反复评价当作三项独立验证。

### 注意力指标及退化检查

- 在 56×56 工作网格比较 `A(rot(x))` 与 `rot(A(x))`，仅在有效交集计算原始数值 MSE，不先逐图归一化美化。
- 同时保存原图与旋转图的注意力原始均值、空间标准差及归一化空间熵。
- 常数图和趋于零的图也可能具有很低的等变 MSE。标准差与熵用于发现这类退化，不能单独证明关注了解剖结构；原始均值也用于识别全低值。
- 如需进一步主张“解剖注意力更合理”，另需预先抽样的医生核验或解剖区域参考。单纯热图更平滑、MSE 更低，不足以支持这一主张。

## 执行顺序与判读

1. 先完成小数据 smoke test，验证两组初始权重、输入、旋转角度、随机路径、BN 更新次数相同；确认零权重确实不引入 EQ 梯度，正权重能够改变梯度。
2. 先运行预定种子 42 的两组，用验证集查看是否存在方向一致的信号。无论正负都保存结果。它仅是机制诊断，不能作为稳健有效结论。
3. 如继续评价该固定设计，补 2026、3407 两个预定种子；不要因第一组不利而替换种子，也不要反复改参数直到验证集变好。
4. 若只有注意力 MSE 下降，分类稳定性没有改善，结论应限于“约束改变了注意力的旋转一致性”；若注意力退化，则这一表面改善也不能作为有效机制证据。
5. 若旋转稳定性改善但原图准确率下降，完整呈现取舍。没有预先确定合理非劣界限时，不能事后把小幅下降写成已证明非劣。
6. 当前测试集已被反复查看，不继续用于选方案。后续用于确认技术效果的数据应来自未参与本次选择的新患者或真正未使用的留出患者。

## 成本与暂缓项

若服务器训练集仍为 446 张、batch size 为 32，每轮 14 个更新步骤。两组各 25 轮，总计 700 个更新步骤，每个步骤均执行主图及旋转图两个 forward；三个种子合计 2,100 个更新步骤，另有验证推理。具体 GPU 小时需根据服务器首轮日志实测，不预估虚假时间。固定预算可能比历史早停运行更久。

首轮不增加 ResNet 重训、完整 CBAM、其他注意力模块、PF 参数扫描、大角度旋转、不同裁边或多个 BN 策略；这些同时变化会削弱对 EQ 贡献的解释。也不重复已有合成白块压力测试来替代旋转验证。

## 评价命令和输出

独立评价脚本为 `scripts/evaluate_rotation_pairs.py`，只接受 `--split val`。`eq_off` 对应上文的 `eq_sham` 对照。配套训练入口完成两组训练后会调用评价脚本；下列命令也可单独运行，目录名按实际训练输出替换：

```bash
python -m scripts.evaluate_rotation_pairs \
  --eq-off-checkpoint rotation_ablation_runs/seed_42/eq_off/last_model.pt \
  --eq-on-checkpoint rotation_ablation_runs/seed_42/eq_on/last_model.pt \
  --splits-dir data_splits_patent \
  --image-root dataset \
  --split val \
  --output-dir rotation_ablation_runs/seed_42/rotation_val \
  --device cuda \
  --batch-size 32 \
  --angles -15 -10 -5 0 5 10 15 \
  --bootstrap 10000 \
  --seed 20261020
```

输出 `per_image_predictions.csv`、`summary.csv`、`paired_comparison.csv`、`metadata.json` 和 `summary.md`。`scope=nonzero_mean` 为预定非零角度平均，`scope=angle` 为单角度。概率单位为 0–1，差值方向为 `eq_on − eq_off`。每个原图、角度和模型仅有一行；角度 0 不进行插值或重复推理。

评价会读取旁边的 `run_config.json` 和上级 `pair_metadata.json`（若存在），核对受控训练协议的初始化、共享参数、输入增强流、固定预算检查点哈希，以及本次 `val.csv` 与训练记录的文件哈希。一旦发现矛盾就停止，而不是继续生成“受控”结果。没有这些记录时会明确标为训练身份未核验。已有非空输出目录不会覆盖。

## 已覆盖与尚未覆盖的问题

本设计可检查 EQ 梯度是否在相同辅助计算条件下改善小角度旋转行为，并排查注意力退化。它不能单独确认 PF 的作用、额外前向的总影响、真实反光鲁棒性、临床用途、专利新颖性或外部患者泛化。若两组没有清晰收益，应如实记录并调整技术方向，而不是更换展示指标来形成优势。
