# ResNet-18整体微调：5-shot训练患者敏感性检查

本轮回答一个问题：保持模型和训练流程相同，只更换用于训练的5位患者，原来的强CE基线会波动多少？这是正式训练的小型开发性检查，不是新算法效果或专利新颖性验证。

冻结线性头的100套抽样结果不能代表整体微调。因此，本轮直接复用同患者关系实验中的普通CE训练实现，不添加几何、对比或患者关系损失。

## 固定方案

| 项目 | 设置 |
|---|---|
| 数据 | 已核验renew的31位患者、93张图，患者隔离五折保持不变 |
| 训练数据 | 每折选5位训练患者，每人提供三类各1张，共15张，即每类5-shot |
| 更换次数 | 预先固定5套支持，每套包含五折，共25次训练 |
| 模型 | ImageNet预训练ResNet-18，Dropout(0.3)加三类线性头 |
| 更新方式 | 先140次分类头更新，再560次整体微调；每步完整15图；BN运行统计冻结 |
| 随机性 | 所有任务训练种子42；每套每折重新从预训练权重初始化 |
| 选样 | `2026111201 + draw*5 + fold`，排序该折训练患者键后用局部随机数打乱，取前5位 |
| 模型选择 | 固定最后一次更新，不用留出集挑轮数、参数或患者 |
| 评价 | 单张RGB输入；每套五折完成后，每张图恰好留出预测一次，共93张 |

`draw`和`fold`均从0到4。完整25份训练名单在第一次训练前保存。沿用原图像顺序和训练增强规则；更换图片后实际增强张量自然不同，因此不要求像素指纹相同。固定训练种子只控制这一轮的训练随机条件，不估计不同训练种子带来的波动。

这五套不从已知的100套冻结实验结果中挑选，不因与旧抽样随机重合而替换。原支持集上的81/93、82/93只作历史参照，不混入新五套的均值和标准差。

## 服务器执行

在原来的`airway`环境中运行。沿用Git同步，无需额外代码压缩包：

```bash
cd /opt/data/private/AirwayRecognition
git pull --ff-only

bash scripts/run_ce_support_server.sh check \
  --image-root dataset/renew \
  --output-root outputs/renew_ce_support
```

`--image-root`必须直接包含93张PNG；如果之前实际用的是`dataset/renew/气管镜`，检查和运行都改为该路径。检查会验证数据及固定计划；正式训练还会检查CUDA和运行环境。

检查通过后启动：

```bash
nohup bash scripts/run_ce_support_server.sh run \
  --image-root dataset/renew \
  --output-root outputs/renew_ce_support \
  > renew_ce_support.log 2>&1 < /dev/null &

tail -f renew_ce_support.log
```

`Ctrl+C`只退出日志查看，后台训练继续。正式运行需要GPU，不读取深度教师或冻结特征缓存。根据旧CE训练循环计时，25次约需3.4 GPU小时，另有数据核验、模型保存及评价开销；请用本次实际进度估计完成时间。

中断后重复同一`run`命令：已完成且通过核验的任务跳过，未完成任务保留到`incomplete_attempts`后重新开始。脚本不恢复单次训练中途的优化器状态。完成标记存在但校验失败时会报错，不静默重训覆盖。

`--draws 0 1`或`--folds 0`可选择固定计划的子集，用于分批执行；默认运行所有25次。不要修改代码、数据、环境或实验设置后复用同一输出目录。

## 训练结束后

```bash
bash scripts/run_ce_support_server.sh status \
  --output-root outputs/renew_ce_support

bash scripts/run_ce_support_server.sh pack \
  --output-root outputs/renew_ce_support
```

只有全部25次正式训练通过核验才能打包。将打印出的结果`.tar.gz`和`.sha256`拉回分析即可。结果包含计划、预测、训练历史、指标和错误频次，不包含图片或权重；模型保留在服务器各任务目录。

`status`与`pack`使用保存的预测记录，无需GPU、原始图片或模型权重。工程用`--smoke`使用随机权重及两次更新，须使用独立输出目录，不能混入正式结果或打包为正式结果。

## 结果怎么判断

1. **主要看5套各自判对多少张。** 同时报告准确率均值、标准差、最少和最多正确数，不只挑最好一次。
2. **看错误随选样是否改变。** 区分五套都错的图、偶尔错的图，并核对各类召回和逐折变化。
3. **保留解释边界。** 五套只能初步描述固定训练种子下的支持敏感性；465条预测仍来自同一31位患者，不能当成465位独立患者，也不是外部验证。

如果换训练患者时正确数和错图明显改变，再讨论怎样只依据可用训练数据选择更有代表性的患者，并单独验证选样算法。如果五套表现接近，就暂时不优先投入该方向。这里不设置统计显著性或专利成功门槛，也不会自动开始下一轮实验。
