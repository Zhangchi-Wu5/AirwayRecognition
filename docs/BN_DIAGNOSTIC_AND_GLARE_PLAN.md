# BN 诊断与抗反光修改方案

当前已实现的是独立的 BN 统计量诊断。抗反光训练和掩膜改法仍是待验证方案，尚未修改现有训练流程，也没有新实验结果证明它们会提升性能。

## 1. 先运行现有权重的 BN 对照

当前训练代码冻结主干时只冻结可学习参数，BN 运行统计仍可能更新；完整方案的旋转正则还会额外做一次训练模式前向。这些是可确认的代码行为，但还不能证明它们造成了性能下降。

新脚本对基线与完整方案分别进行：

1. 保留原始权重，在验证集评估干净图和固定反光图。
2. 仅用 `train.csv` 的图像重估 BN 运行均值、方差及批次计数。使用固定预处理、关闭 Dropout、不用标签、不计算梯度。
3. 在完全相同的验证图和反光扰动上重新评估。

脚本检查训练/验证患者及解析后图片路径不重叠，校验所有可学习参数和其他缓冲区不变，不保存或覆盖模型权重。评估只允许 `val`，不读取测试集。

在服务器项目根目录、已激活的 `airway` 环境运行，先检查 seed 42：

```bash
python -m scripts.diagnose_bn_stats \
  --baseline-checkpoint patent_runs/seed_42/baseline/best_model.pt \
  --full-checkpoint patent_runs/seed_42/full/best_model.pt \
  --splits-dir data_splits_patent \
  --image-root dataset \
  --output-dir patent_runs/seed_42/bn_diagnostic_v1 \
  --device cuda --batch-size 16 \
  --coverages 0 0.05 0.10 0.20 \
  --placements 10 --seed 20261019 --bootstrap 10000
```

其余两组用于核查结论是否跨训练种子一致，不能只挑改善的一组：

```bash
for training_seed in 2026 3407; do
  python -m scripts.diagnose_bn_stats \
    --baseline-checkpoint "patent_runs/seed_${training_seed}/baseline/best_model.pt" \
    --full-checkpoint "patent_runs/seed_${training_seed}/full/best_model.pt" \
    --splits-dir data_splits_patent --image-root dataset \
    --output-dir "patent_runs/seed_${training_seed}/bn_diagnostic_v1" \
    --device cuda --batch-size 16 \
    --coverages 0 0.05 0.10 0.20 \
    --placements 10 --seed 20261019 --bootstrap 10000 || break
done
```

现有专利实验对应默认的完整方案黑边裁剪、普通分辨率注意力。其他权重必须匹配训练时的配置：高分辨率注意力加 `--full-attn-hires`，完整方案未裁黑边加 `--no-full-crop-border`，基线裁黑边加 `--baseline-crop-border`。

输出目录不能已有结果；重跑请换新名称。成功结束时才写入 `metadata.json` 的 `completed: true`。输出包括：

|文件|用途|
|---|---|
|`summary.md`|中文校准前后结果，优先查看|
|`bn_effect.csv`|每个模型内部的“校准后 − 校准前”差值和患者配对 Bootstrap 区间|
|`bn_changes.csv`|每一层 BN 统计及计数的变化|
|`metadata.json`|配置、权重哈希、划分信息及参数不变校验|
|`original/`、`recalibrated/`|各自的逐图概率、汇总及完整方案减基线的配对比较|

`bn_effect.csv` 中准确率差大于零表示改善，翻转率、共同正确变错率、真实类别概率下降的差小于零表示改善。共同正确队列指**同一个模型在校准前后对干净图都预测正确**，不是两种模型共同正确的队列。

结果解释：

- 完整方案改善：说明其当前权重对 BN 统计敏感，支持统计不匹配是候选因素。
- 两种模型都改善：可能存在共同的训练/推理分布不匹配，不能直接归因于完整方案额外前向。
- 没有改善：仍不能排除 BN 在训练中影响了已经学到的参数。
- 不要将两种不同共同正确队列的差值相减，声称证明了因果交互。

校准采用固定图像排序，逐批使用“本批图像数 / 已累计图像数”的 momentum，短尾批也按图像数加权。方差是各批无偏方差的样本加权均值，不是精确合并的全数据方差。批大小会影响校准结果；应固定协议，避免根据测试成绩挑选校准参数。此操作不是中性的必然修复。

要确定训练阶段的影响，还需要相同初始化、数据顺序与训练配置的对照重训，只改变旋转辅助前向是否更新 BN 运行统计，同时保持该前向使用当前批统计及原有梯度路径。直接把辅助前向切到 `eval()` 会同时改变归一化行为，不能算只改变更新次数。冻结主干时是否冻结 BN 应另设一组，避免同时改多个因素。

## 2. 抗反光训练应直接约束预测

目前抑制高光区域注意力、要求旋转后注意力对齐，都不能保证分类概率对反光稳定；分类头还包含全局特征分支。候选改法是在共享几何变换后构造同图轻度高光配对，同时训练原图与高光图分类，并小权重加入预测分布一致性：

```text
损失 = 原图分类损失 + α × 高光图分类损失 + λ × 两图预测分布的 JS 差异
```

一致性训练有公开先例，例如 [AugMix](https://arxiv.org/abs/1912.02781)；这里是针对本项目的候选组合，不是其原始算法的复现，也不能将通用一致性损失单独视为新增创新点。

优先比较普通 ResNet 原始训练、普通 ResNet 加同图反光训练、完整方案加相同反光训练。保持各组预处理与数据预算可比，才能区分增强与结构的贡献。原图分类不能丢；遮挡已使关键解剖结构不可辨认时，不应强迫输出不变。

合成高光应覆盖多种位置、形状、软边和强度，记录视野内实际覆盖比例。现有近白方块只是压力测试，不能只用相同模板训练并宣称真实反光鲁棒性。训练和验证扰动种子分开，保留真实高光子集检查效果；调参用验证集，已查看过的测试集不用于反复选方案。

## 3. 掩膜和数据是否要额外处理

现有掩膜自动生成，无需逐图人工分割。它在增强后的 224 输入缩小到 56 后检测高亮、近白区域，再过滤小连通区域。小亮点可能因缩图或面积过滤消失，颜色增强也会改变是否越过阈值。

本地固定 seed 42、446 张训练图各一次增强的检查中，53 张得到非空掩膜、393 张为空；同一批几何变换下，颜色增强前后有 50 张由非空变空，11 张由空变非空。这是当前代码抽样检查，不是服务器历史训练日志，也没有人工高光真值，不能把空掩膜率等同于漏检率。

建议先人工查看一批原图、增强图和掩膜的叠加图，区分没有明显高光、漏检和正常亮组织被误判。随后尝试在 224 尺度先检测，再用面积平均缩小为软掩膜。最小连通面积要按尺度换算：56 尺度的 4 像素约对应 224 尺度的 64 像素，不能只比较非空率就认定检测改善。

若掩膜定义为“当前图像可见的饱和亮区”，应在颜色增强后检测；若定义为“原图反光位置”，可预先生成，但必须与图片共享裁剪、旋转参数，并说明颜色改变后标签的含义。合成高光的覆盖区域已知，可直接生成掩膜。

暂时不必重新抽取全部数据。增加样本时，先按患者划分，患者的所有视频和帧保持在同一集合；抽帧保留可辨认的真实反光、角度和设备变化，控制邻近重复帧。新增多帧须保留唯一图片标识、患者、视频及时间戳，避免文件覆盖或拆散同一患者。若现有训练集确实缺少真实反光，再补充有代表性的训练样本。

## 4. “干净验证集”的含义

“干净”只表示**没有额外添加随机旋转、颜色扰动或合成反光**。验证预处理为可选黑边裁剪、Resize256、中心裁剪224和标准化。原图自带的自然反光、拍摄角度、模糊仍可能存在。

训练集则包含随机裁剪、±15°旋转和颜色扰动。因此干净验证集不等于专门筛选出的无反光、端正图像集合。
